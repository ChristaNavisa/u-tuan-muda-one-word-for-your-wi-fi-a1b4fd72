One word for your Wi-Fi: **Peekaboo**.

The signal plays peekaboo — there one second, gone the next, back again
just when you stop looking. Every room in the house knows the game.

## Run

```sh
node main.ts
```

Writes one word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Entry

```
Peekaboo
```
